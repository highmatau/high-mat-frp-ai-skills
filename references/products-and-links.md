# High-Mat product families and web pages

Base: https://high-mat.com.au

## Pultruded profiles (121 sizes, each with a STEP model)

| Code prefix | Family | Sizes | Code pattern |
|---|---|---|---|
| HM CS | C channel | 16 | height x width x t x t |
| HM IB | I-beam | 18 | width x height x flange t x web t |
| HM WF | Wide flange | 11 | height x width x t x t |
| HM EA | Equal angle | 15 | leg x leg x t |
| HM RHS | Rectangular hollow section | 8 | height x width x t |
| HM SHS | Square hollow section | 18 | side x side x t |
| HM RT | Round tube | 11 | outside diameter x t |
| HM FP | Flat plate | 7 | 1000 wide x t (3.2 to 25.4) |
| HM FS | Flat strip | 17 | width x t |

Solid round (RSR/RSB) and square (SSR/SSB) bars are also sold; no data is published.

STEP URL pattern: `https://high-mat.com.au/technical_frp_pultrusions/Profile Photo/<folder>/<file>.STEP` (exact, working URL for each profile is in `data/profiles.csv`, column `step_url`). A profile image sits beside it with the same name and `.jpg`.

| Code prefix | Family | Codes |
|---|---|---|
| HM MG-S | Moulded, square mesh | 23 |
| HM MG-MINI | Moulded, mini mesh | 10 |
| HM MG-MICRO | Moulded, micro mesh | 3 |
| HM MG-ST | Moulded, solid top (3 or 5 mm plate) | 18 |
| HM MG-R | Moulded, rectangular mesh | 8 |
| HM PGI | Pultruded, I-bar | 15 |
| HM PGT | Pultruded, T-bar | 9 |
| HM HDPG | Pultruded, heavy-duty bar | 3 |

Fixings: clip families M, C, L, D, E, S, W, G, H, J, T, U and mini-mesh versions. A clip letter names a family, not a load rating; spacing and fasteners come from the project connection schedule.

## Other products and systems

Stair treads (mini, square, micro mesh); safety gates HM-G8, HM-GA, HM-GP; handrails and kickplates; fixed and caged ladders; FRP bolts, nuts, washers, threaded rod; access platforms, stairs, crossovers, walkways, ramps, pedestrian bridges, trench and pit covers, access hatches, baffle walls, fencing, shelters, tank supports, cable ladder, benches; vacuum-infused panels and light RTM mouldings.
